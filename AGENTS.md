# Cloudkeepers

Standalone family browser game. This is not an AIFit or Ez project.

- The family is developing this in stages. Current scope is scene, assets, and characters. Do not add maths, adaptive learning, rewards, or level rules until requested.
- Keep a playful, premium storybook look, with original local assets, touch and keyboard controls, and accessible dialogs.
- Keep the prototype dependency-free. Run `npm run dev`, inspect it in a browser, and use `npm run build` to verify a shareable static build.
- Preserve local player preferences separately for Daniela and Sofia. Do not represent exploration or demo interactions as maths progress or animal rescues.
- The child is a co-designer. Honour her creative descriptions; tentative island/animal names are concept art, not fixed curriculum design.
